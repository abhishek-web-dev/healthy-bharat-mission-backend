# Healthy Bharat Mission - Backend

This directory contains the PHP backend for the Healthy Bharat Mission project. 

## Architecture
- PHP 8.3+
- MySQL with PDO
- MVC / Service-based Architecture

## Directory Structure
- `config/` - Environment & database configuration
- `controllers/` - Request handlers
- `database/` - Schema & migrations
- `helpers/` - Utility functions
- `middleware/` - Auth & security filters
- `models/` - Data structures
- `public/` - Entry point & public assets
- `repositories/` - Data access layer
- `routes/` - API endpoints
- `services/` - Business logic
- `uploads/` - User-uploaded files
